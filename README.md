# Library Management System

A simple **Library Management System built with C#** to practice Object-Oriented Programming, collections, and file handling.

## Features

* Add and manage books
* Add and manage library members
* Borrow and return books
* Display books and members
* Show borrowed books
* Save and load library data from files

## Technologies

* C#
* .NET
* Object-Oriented Programming
* `List<T>`
* File I/O
* Visual Studio

## Project Structure

```text
Library_Management_System/
├── Book.cs
├── Member.cs
├── LibraryManager.cs
├── FileManager.cs
└── Program.cs
```

## How to Run

Clone the repository:

```bash
git clone https://github.com/jahanzaibkhan1995/week4_Library_Management_system.git
```

Open the solution in **Visual Studio** and run the project.

Or, using the .NET CLI:

```bash
dotnet build
dotnet run
```

## Learning Goals

This project was created to practice:

* Classes and objects
* Class relationships
* `List<T>` collections
* Basic LINQ/search operations
* File-based data persistence
* Git and GitHub workflow
